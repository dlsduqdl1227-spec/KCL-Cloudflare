# 20260731 업데이트

## 공통 뒤로가기 버튼 통합

- 같은 이동 함수를 호출하던 상단 `이전`과 휴대폰 하단 `뒤로가기`의 중복을 제거했습니다.
- 휴대폰과 PC 모두 상단의 `← 뒤로가기` 한 개만 사용합니다.
- 검수 목록·검수 상세·순위 화면에 따로 있던 동일 목적의 뒤로가기/목록 버튼도 화면에서 제거하고 공통 버튼으로 통일했습니다.
- `홈`은 현재 화면의 이전 단계가 아니라 앱 첫 화면으로 이동하는 별도 기능이라 유지했습니다.

## 컵·샘플별 평가 상태 독립

- KCR 스마트태그 카테고리 펼침 상태를 전체 평가 화면 공용 값에서 각 컵 전용 값으로 변경했습니다.
- 1번 컵에서 `견과·코코아 계열`을 열어도 새 2번 컵에서는 아무 카테고리도 자동으로 열리지 않습니다.
- 다시 1번 컵으로 돌아가면 1번 컵의 화면 상태만 복원되며, 점수·강도·태그·속성 코멘트·종합 코멘트도 기존처럼 각 컵 객체에만 저장됩니다.
- 이전 버전 임시저장을 복원할 때 공용 카테고리 상태를 모든 컵에 복제하지 않도록 호환 처리를 추가했습니다.
- KCR 임시저장 복원 중 화면에 남아 있던 값을 복원 데이터 위에 다시 저장할 수 있던 경로를 제거했습니다.

## 전 대회 독립성 점검

- KCR: 컵별 객체 저장 및 제출 시 컵별 행 분리.
- IKRC: 샘플별 객체 저장, 샘플 전환 시 해당 샘플의 태그만 렌더링, 제출 시 샘플별 행 분리.
- KCAC: 잔별 점수·스마트태그·코멘트 객체와 잔 번호가 포함된 카테고리 열림 키 사용.
- MOC·KTCC: 참가자·팀을 바꾸기 전에 현재 입력을 대상별 스냅샷으로 저장하고 대상 전용 스냅샷만 복원.
- KBC·MOB: 한 번에 한 참가자를 평가하며 새 평가 시작 시 스마트태그 열림 상태 초기화.

## 자동검사

- 공통 뒤로가기 버튼이 정확히 한 개만 존재하는지 검사합니다.
- 새 KCR 컵에서 스마트태그 카테고리가 닫힌 상태인지 검사합니다.
- 1번 컵의 펼침 상태가 2번 컵으로 이동하지 않는지 검사합니다.
- KCR·IKRC·KCAC·MOC·KTCC의 대상별 상태 저장 구조를 검사합니다.
- 같은 심사위원의 서로 다른 컵과 서로 다른 심사위원의 같은 컵이 서버에서 각각 독립 행으로 저장되는지 통합 검사합니다.

## MOB 검수·디브리핑 점수 표시 정리

- 검수 목록과 검수 상세에서 `총점`, `테크니컬 총점`, `센서리 총점`, `창작메뉴 총점`, `감점 전 합산`, `감점 적용 후 점수`, `순위 반영점수`, `총평가 반영점수`를 숨겼습니다.
- 디브리핑의 심사위원 카드와 상단 요약에서도 같은 파생 점수를 반복 표시하지 않습니다.
- 실제 심사위원이 입력한 평가속성 점수·코멘트와 필요한 시간감점 정보만 확인할 수 있습니다.
- 파생 점수는 화면에서만 숨기며, 순위 계산·검수 수정 후 재계산·백업 및 엑셀 원본에는 계속 저장됩니다.
- MOB 표시 전용 회귀검사를 추가해 파생 점수가 다시 검수·디브리핑에 노출되지 않는지 자동 확인합니다.

## IKRC 스테이션 추가·삭제

- IKRC 대회팀장·관리자의 `스테이션·블라인드 배정` 화면에 스테이션 관리 영역을 추가했습니다.
- `+ 스테이션 추가`, 각 스테이션의 `삭제`, `스테이션 설정 저장`을 같은 화면에서 사용할 수 있습니다.
- 작은 `×` 삭제 버튼을 알아보기 쉬운 `삭제` 버튼으로 변경했습니다.
- 중간 스테이션 삭제 후 새로 추가해도 코드가 중복되지 않도록 사용하지 않는 다음 코드를 자동 선택합니다.
- 스테이션 삭제·범위 변경 시 기존 평가점수와 백업 데이터는 삭제하지 않습니다.
- 변경 범위에서 벗어나는 선수 배정이 있으면 저장 전·후에 인원수를 표시하며, 기존 점수는 제출 당시 스테이션 정보로 유지합니다.
