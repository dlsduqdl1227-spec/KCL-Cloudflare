# KCR 선택 스테이션 표시 · 헤드 우선 정렬

## 수정 범위

- 켈리브레이션 확인 우측 상단은 조회 가능한 스테이션 **개수**를 표시하고 있었다. 이를 `선택 스테이션` / 실제 선택한 `스테이션 3` 등의 명칭으로 변경한다. 선택을 바꾸면 즉시 갱신하며 빈 목록에서는 `—`를 표시한다.
- 켈리브레이션/대회평가의 스테이션 비교표 및 코멘트는 헤드심사위원 먼저, 일반 심사위원 다음으로 표시한다. 동일 역할 내부의 기존 순서는 유지하고 원본 배열을 복사하여 화면에서만 정렬한다.
- 특정 스테이션 번호를 켈리브레이션에 고정하지 않는다. 기존 용도 설정 로직을 유지하며 실제 대회 운영 설정의 `useForCalibration` / `useForCompetition`에 따라 입장 목록이 구분되는 것을 검증했다. 기존 켈리브레이션 제출 기록은 용도 변경 후에도 삭제하지 않는다.
- 서버, 점수 계산, 저장, 권한, 스테이션 설정 및 다른 대회 코드는 변경하지 않았다. 표시 변경은 평가 페이지의 두 함수에 한정한다.

## 검증

- 기존/신규 회귀 96개 및 KCR 비교 브라우저 2개: 총 98개 테스트 명령 통과.
- 실제 RPC와 폐기 가능한 로컬 DB에서 1번을 대회평가용, 3번을 켈리브레이션용으로 변경 후 평가 입장 목록 검증.
- 360/768/1440px에서 3번 스테이션 1개만 조회 가능한 헤드 계정의 상단 표시, 참가자 전환, 헤드 우선 점수/코멘트 순서, 가로 넘침, JavaScript 오류 확인.
- 관리자 계정의 3번→4번→1번 전환과 빈 목록 헤더 초기화 검증.
- 공식평가 목록의 스테이션 비교와 본인 검수 상세 비교 모두 동일한 표시 순서 확인.
- 화면 렌더링 전후 통계 객체, 점수 DB, 설정 DB가 그대로 유지됨을 검증.
- Pages Functions 빌드 성공. 운영 DB를 사용한 테스트 제출/수정 없음.
