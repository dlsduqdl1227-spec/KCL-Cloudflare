# KCR 헤드심사위원 스테이션 비교

## 적용 내용

- 헤드·대회팀장·관리자 메뉴에 별도 `켈리브레이션 확인` 진입을 제공한다.
- 켈리브레이션 결과는 스테이션/참가자번호를 선택하여 읽기 전용으로 확인한다. 대회평가·순위 자료와 합치지 않는다.
- 사전 고정 팀을 만들지 않는 현재 운영 방식에 맞춰, 헤드 본인이 해당 목적(켈리브레이션 또는 공식평가)으로 제출한 스테이션을 담당 범위로 판단한다. 같은 라운드의 스테이션 고유 ID를 우선 사용한다. 헤드가 다른 스테이션에서 새로 제출하면 해당 스테이션도 확인할 수 있다.
- 대회팀장·관리자는 모든 스테이션을 확인한다. 일반 심사위원에게 다른 심사위원의 점수·코멘트를 반환하지 않는다. 클라이언트에서 관리 권한이나 스테이션을 임의로 지정해도 서버 권한은 확장되지 않는다.
- 전체 심사위원과 헤드 그룹 각각의 총점·항목별 평균 및 모집단 표준편차를 표시한다. 헤드 간 비교표와 각 심사위원의 점수/전체 평균 대비 차이(+/−)를 구분한다. 비교 대상이 2명 미만이면 표준편차를 0으로 강조하지 않고 미표시한다.
- 종합코멘트와 항목별 코멘트를 심사위원별로 표시한다. 코멘트를 자동 생성하거나 원본을 수정하지 않는다.
- KCR 후미·단맛의 실제 저장 항목명을 통계 조회에 포함하여 누락된 값을 가짜 0으로 집계하지 않도록 한다.
- 공식평가 `내평가검수`는 헤드 본인의 점수·코멘트 수정 기능을 유지한다. 완료 기록도 목록에서 유지하며, `스테이션 비교`와 검수 상세의 비교 영역으로 같은 스테이션의 저장된 점수를 확인한다. 다른 심사위원의 기록은 헤드가 수정할 수 없다.
- 검수 상세의 `통계 새로고침`은 비교 영역만 갱신하고 작성 중인 점수·코멘트·잠금 상태를 다시 렌더링하지 않는다.
- 검수 목록 캐시는 계정/대회/조회 목적/권한 문맥별로 분리한다. 이전 요청이 늦게 도착하거나 문맥 변경 후 실패·재시도하더라도 다른 화면의 자료를 재사용하지 않는다.
- UI 변경은 KCR 비교 화면에 한정한다. 다른 대회 점수 산식, 공개 상태, 라운드, 선수/심사위원 배정은 변경하지 않는다.

## 검증

- 기존 및 신규 회귀 테스트 명령 96개 통과.
- 브라우저 테스트 201, 203, 204, 206, 208, 210, 212 모두 통과.
- 신규 API 테스트: 헤드 2명·일반 심사위원 1명, 별도 스테이션 헤드, 제출 전 헤드, 관리자, 팀장 계정으로 접근 범위/점수/코멘트/본인 수정/타인 수정 거부 검증.
- 총점 21/28/35의 평균 28, 모집단 표준편차 5.7155; 헤드 21/28의 평균 24.5, 표준편차 3.5를 독립 계산값과 대조.
- 360/768/1440px에서 켈리브레이션 조회, 참가자 전환, 본인 검수, 통계 갱신, 점수·코멘트 입력값 유지, 화면 가로 넘침 및 JavaScript 오류 점검.
- 모바일 비교표는 표 영역 안에서 가로 스크롤하며 페이지 자체의 가로 넘침은 없음.
- KCR 검수 화면은 PC에서 최대 1120px, 모바일에서 화면 폭을 사용한다. 상단 뒤로가기/홈 영역과 겹치지 않으며 통계 새로고침은 글자가 잘리지 않는 별도 버튼이다.
- KCR 검수는 상단 고정 `수정완료` 버튼을 유지하고 하단의 중복 저장 바만 숨겨 비교표를 가리지 않게 한다. 다른 대회 검수 화면에는 적용하지 않는다.
- 운영 API에 평가/검수 테스트 제출 없음. 폐기 가능한 로컬 DB와 실제 RPC 구현으로 쓰기 검증.
- Pages Functions 빌드 성공.

## 실제 기기 확인 범위

브라우저의 가로 폭별 자동 검증을 수행했으며 현장 심사위원의 실제 휴대폰이나 카카오톡 내장 브라우저를 직접 조작하지 않았다. 통계는 제출·저장된 값 기준이고 저장 전 다른 기기의 작성 내용까지 표시하지 않는다.
