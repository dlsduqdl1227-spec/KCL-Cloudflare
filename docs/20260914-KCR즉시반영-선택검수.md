# KCR 제출 즉시 반영 · 선택형 검수

## 변경 범위

- KCR 심사 메뉴를 2×2로 정리: 위쪽은 켈리브레이션 / 켈리브레이션 확인, 아래쪽은 대회평가 / 내평가검수. 헤드가 아닌 심사위원에게는 타인 통계 확인 권한을 추가하지 않는다.
- 공식 검수 목록에 스테이션과 참가자번호 선택을 추가한다. 선택한 참가자의 본인 제출 및 권한이 허용된 비교 통계만 표시한다. 관리자는 관리 범위의 제출을 확인한다. 편집 원본 목록은 유지하며 선택한 일부 목록으로 덮어쓰지 않는다.
- `Done 0/10`을 실제 제출 수인 `평가완료 10건`으로 변경한다. KCR에는 별도 검수완료 버튼이 필요하지 않다. 기존 완료 상태의 본인 제출도 계속 수정할 수 있다.
- KCR 순위는 저장된 공식 제출을 검수 상태와 관계없이 포함한다. 헤드와 센서리 모두 포함하며, 켈리브레이션 모드/상태는 제외한다. 예선·결선 분리, 기존 평균 계산·중복 제출 정리·동점 규칙은 유지한다.
- 최종 보고서, 관리자 디브리핑 미리보기와 공개 디브리핑도 같은 공식 제출 기준을 사용한다. 공개 여부 설정 및 선수 인증 요건은 변경하지 않는다.
- 다른 대회의 검수·순위 기준은 변경하지 않는다.

## 기존 기록에 대한 영향

점수·코멘트·검수 상태를 일괄 수정하거나 복원하지 않는다. 기존 `미검수` 공식 제출도 이제 집계에 포함되므로, KCR 평균 및 순위는 새 집계 기준에 따라 재계산될 수 있다. 이는 원점수 수정이 아니다. 선수·스테이션·라운드·공개 설정도 변경하지 않는다.

## 검증

- 회귀 및 브라우저 테스트 106개 명령 통과. Pages Functions 빌드 성공.
- 실제 RPC와 폐기 가능한 로컬 DB로 미검수 즉시 순위 반영, 헤드 포함, 켈리브레이션 제외, 빈 결선에 예선 미노출, 최종 보고서 및 공개/미리보기의 평가표 일치 확인.
- 기존 검수완료 제출을 다시 수정할 수 있고, 수정한 1건 이외의 기록은 그대로 유지되는 것을 확인.
- 360 / 768 / 1440px에서 2×2 버튼 위치, 제출 건수 표시, 참가자별 조회, 헤드 우선 정렬, 수정 후 선택 유지, 본인 코멘트 재열기, 가로 넘침 및 JavaScript 오류 확인.
- 센서리의 타인 점수 미노출, 관리자 다중 스테이션 조회, 켈리브레이션·대회평가 응답 경합 방지 확인.
- 운영 DB 대상 테스트 제출, 삭제, 점수 수정, 일괄 검수완료, 공개 전환 없음.
