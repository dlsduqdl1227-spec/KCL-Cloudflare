# 2026 본·결선 점검

## 반영 범위

현재 운영 중인 예선 점수·코멘트·잠금·스마트태그·선수 명단·공개 설정은 수정하지 않는다. 라운드 전환과 진출 선수 지정은 운영자가 진행한다. DB 이전, 데이터 초기화, 자동 순위 조정은 포함하지 않는다.

## 규정 대조

## KCAC 스마트태그 보존

예선의 스마트태그 원본 목록은 바꾸지 않았다. 언더필, 패턴 식별 어려움, 표면의 기포 없음/광택 유지, 선명도의 크레마 경계·라인 번짐·얼룩 표현을 보존했다.

결선 규정에는 별도 선명도 배점 항목이 없으므로, 선명도 표현은 결선 **표면 품질**의 선택어로 연결했다. 예선 완성도는 결선 **디자인 완성도**, 예선 균형·위치는 결선 **위치 및 대칭**의 선택어로 연결했다. 별도 배점이나 감점을 추가하지 않는다. 저장된 선택값을 일괄 이관하거나 덮어쓰지 않는다.

일반 헤드 권한으로 결선을 시작하면 담당 영역을 한 번 선택한다. 센서리/테크니컬 역할이 지정되어 있으면 담당 영역으로 바로 진입한다. 사진 및 예선 리프 수 없이 결선 제출이 가능하며, 각 잔의 점수·잠금·코멘트는 독립 저장한다.

## 운영 방법

1. 등록·권한 관리 → 선수 → 해당 선수 **수정** → **본·결선 배정 (선택)**을 펼친다.
2. 진출 선수의 해당 라운드 번호와 날짜를 입력하고 **선수 수정완료**를 누른다. KBC/MOC는 본선·결선 각각, 나머지는 결선을 배정한다.
3. 같은 대회의 같은 본선/결선 번호는 다른 선수에게 중복 배정할 수 없다. 예선 번호와 기록은 유지한다.
4. 해당 라운드 심사위원의 역할·적용일을 확인한다. KCAC는 패턴 2명/센서리 2명, MOB는 센서리/테크니컬 구분을 확인한다.
5. 운영 설정에서 해당 대회 라운드를 본선 또는 결선으로 저장한다. 선수 목록에는 그 라운드 번호가 지정된 진출자만 표시된다. KCR은 2026 규정에 맞게 블랜딩 스테이션을 설정한다.
6. 심사 시작 후에는 라운드를 바꾸지 않는다. 도중에 바뀌었으면 다른 라운드로 자동 저장하지 않고 입력을 보존한 채 운영 확인을 안내한다.

## 안전성 및 검증

- 전체 기존 회귀 테스트 통과: 평가→제출→검수, 코멘트 유지, 블라인드, 스테이션, 순위/디브리핑, D1 사용량 등.
- 신규 통합 테스트: 실제 RPC를 메모리 SQLite/D1 어댑터에서 실행. 7개 대회의 진출자 번호 연결, KCAC 헤드 4명/6개 컵 행의 제출·검수·97점 집계, 중복 번호 차단, 라운드 변경 시 기록 보존 확인.
- 신규 브라우저 테스트: 390px/1280px, KCAC 담당 영역 선택·사진 없는 제출·컵별 점수/잠금/코멘트 보존·늦은 AI 응답 차단, KBC 재생성, MOB 예결선 항목 전환, MOC/KTCC 컵 수, IKRC 진입, 등록 화면 본결선 번호/날짜 저장 확인.
- 신규 통신 테스트: 재시도 중 다른 대회/라운드로 이동해도 최초 제출 라운드 유지.
- KCAC 결선 예: 패턴 평균 60 + 센서리 2잔 합산 평균 40 − 시간감점 3 = 97. 각 영역에서 각각 3점을 빼는 94점 집계 방지.
- 운영 DB 점검 시 저장 평가 837건은 모두 예선. 실제 운영 DB에 테스트 평가를 제출하지 않음.

## 규정집에서 확정할 수 없는 내용

- KCAC 9/9 규정집 본문 6.1·6.4·6.6·6.8은 창작패턴 1잔 + 센서리 2잔을 명시한다. 18쪽 부록의 창작패턴 행에는 우유별 1잔씩으로도 적혀 있어 본문과 불일치한다. 기존 앱과 본문의 **총 3잔** 구성을 유지했다. 운영팀에서 부록 오기를 확인해야 한다.
- MOC·KTCC 결선 히든미션의 실제 문제/판정 기준은 규정집에서 별도 공지 대상으로 되어 있다. 임의 항목·가산점을 만들지 않았으며 공지 내용이 달라지면 추가 반영이 필요하다.
- KBC 최신 규정은 시간 차감을 명시하지만 차감 구간표가 확인되지 않았다. 이미 운영 중인 5초당 1점 차감과 실격 유예 기준을 임의로 변경하지 않았다.
- 실제 휴대폰 기종별 카메라·네트워크 및 대회 당일 동시 접속 환경까지 무오류를 보장하는 검증은 아니다. 시작 전 담당 권한으로 짧은 운영 점검이 필요하다.
