# KCR 모바일 입력·Dry 스마트태그 (2026-10-12)

## 수정

- KCR 속성 코멘트의 13px 규칙이 기본 16px 폼 규칙을 덮어쓰던 부분을 전용 스타일로 보완. 평가·검수 입력란은 16px 이상으로 유지.
- KCR 고정 평가/검수 화면을 VisualViewport의 높이·상단 오프셋에 맞춤. 키보드가 떠도 내용 영역에서 스크롤할 수 있으며 현재 입력란만 필요한 만큼 이동. 점수·태그·코멘트 DOM을 다시 생성하지 않음.
- 의도적인 핀치 줌은 유지하고, 확대 중에는 뷰포트 크기를 쫓아 재배치하지 않음. KCR 버튼은 touch-action:manipulation으로 처리해 빠른 연속 터치가 기존 touchend 취소 로직에 막히지 않도록 함.
- 키보드 표시 중 검수 속성 탭이 코멘트 위에 겹치지 않도록 보완. 다른 대회 화면에는 해당 동작을 적용하지 않음.
- 선택된 컵의 글자 대비 개선. 컵 탭을 다시 그릴 때 가로 위치를 유지하고 현재 컵이 화면 안에 있도록 조정.
- 산미 > 보완 표현에 `드라이한 / Dry` 추가. 속성 자동 코멘트, 저장, 검수, 디브리핑 태그 해석에 반영.
- 대회 전용 태그 메타데이터를 두어 신규 Dry가 공유 스마트태그를 통해 다른 대회에 자동 추가되지 않도록 차단.

## 검증과 범위

- 격리된 로컬 SQLite와 실제 RPC 코드로 검증. 운영 DB에는 테스트 평가를 제출하거나 기존 점수·코멘트·스테이션을 변경하지 않음.
- 320/390/768/1440px, 9컵 이동, 점수 잠금·코멘트 독립성, Dry 저장·검수 재수정, 중복 없는 9건 유지, 제출 버튼 도달성 확인.
- 휴대폰 입력 환경 에뮬레이션 및 합성 VisualViewport 이벤트로 키보드 높이·오프셋·핀치 줌 분기를 검증. 실제 iPhone Safari의 네이티브 키보드/자동 확대 동작은 이 환경에서 직접 검증하지 못함.
- 기존 전체 회귀 테스트와 KCR 스테이션/헤드 비교/예선 일차/즉시 순위/중복 제출/블라인드/9컵 테스트를 실행. 리소스 버전 고정 검사도 신규 버전에 맞춰 갱신.

참고: [MDN VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport), [MDN touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action).
