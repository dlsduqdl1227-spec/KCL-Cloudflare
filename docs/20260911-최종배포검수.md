## 2. 직접 수정한 내용

- 선수 목록, 권한 목록, 선택 삭제 목록에 최신 요청 확인을 추가했다. 대회를 바꾸면 이전 응답은 화면에 반영하지 않는다.
- 선택 삭제는 현재 대회에서 정상적으로 불러온 목록에 대해서만 실행할 수 있게 했다. 실제 삭제 테스트는 운영 DB에서 하지 않았다.
- 선수 목록 조회 실패 시 해당 대회의 기존 목록을 유지하고 조회 실패를 별도로 표시한다.
- 선수 저장은 중복 요청을 막고, 실패 시 입력을 유지한다. 저장 완료 시에도 요청 이후 입력이 바뀌었다면 폼을 지우지 않는다.
- 관리자 권한 갱신 재시도는 1회로 제한했다.
- 관리자 디브리핑 미리보기는 선택 대회와 요청 순서를 확인하고, 늦게 도착한 이전 결과를 무시한다. 선수/미리보기 공통 렌더러는 유지했다.
- 로그인 버튼의 처리 중 상태, 오류 후 재시도, Enter 제출을 정리했다.
- 카메라 요청 중복과 늦은 스트림 응답을 차단하고 영상 준비 후 그리도록 했다. 페이지 종료 시 스트림을 중지한다.

점수 공식·스마트태그 내용·운영 명단·권한·대회 라운드·공개 여부는 변경하지 않았다. 실제 평가/검수/선수 등록을 운영 서버에 시험 제출하지 않았다.

## 3. 디자인·사용성 개선

- 기존 검정/흰색 중심 디자인을 유지했다.
- 모바일 MOB/KCAC의 개별 점수와 합산 영역을 제목 아래 한 줄로 배치해 잘림을 방지했다.
- 등록 관리의 선수·심사위원·관리자 탭이 360px에서도 모두 보이도록 했다.
- PC 평가 본문의 최대 폭을 제한해 지나치게 긴 줄을 줄였다.
- 긴 완료/오류 안내가 모바일 폭 안에서 줄바꿈되도록 수정했다.
- 로그인 입력에 항상 보이는 이름표를 제공하고 입력값·버튼의 간격을 통일했다.
- 공통 키보드 포커스, 본문 바로가기, 탭 방향키, 버튼형 요소의 Enter/Space 조작, 상태 알림을 보완했다.
- 사용자의 화면 확대를 허용하고 터치 환경의 입력 글자 크기를 보완했다.
- 카메라 가이드 방향키 조절, 사진 확대창 Escape 닫기·포커스 복귀를 추가했다.
- 6개 페이지의 제목·설명을 정리했다. 인증/운영 페이지는 검색 노출을 제한하고 홈은 검색 가능하게 유지했다.
- 공통 UI 보완은 별도 CSS/JS로 분리했다. 대회별 계산·저장 로직은 공통화하지 않았다.

## 4. 남아 있는 문제와 이유

- 실제 iPhone/iPad/Android 기기와 Safari, 실제 카메라 하드웨어, 통신사 문자 수신은 이번 자동 검수에서 검증하지 않았다. 로컬 Chrome의 여러 화면 폭 검증과 실제 기기 검증은 동일하지 않다.
- 모든 사용자·모든 예외 상황을 포함한 무오류나 실전 동시 접속 성능을 보장하지 않는다. 운영 DB에 대량 시험 쓰기를 하지 않았다.
- 일부 원본 평가 사진은 약 8~10MB다. 평가 근거 사진을 임의 압축/교체하지 않았다. 별도 미리보기 이미지를 만드는 방식이 적합하다.
- 평가 페이지는 여러 대회 기능이 큰 파일에 모여 있다. 즉시 전면 분리하면 운영 회귀 위험이 커서 이번에는 공통 UI와 테스트 도구만 분리했다.
- 본·결선 규정의 KCAC 부록/본문 잔 수 불일치, MOC·KTCC 히든미션, KBC 시간감점 구간 확인 사항은 `20260911-본결선점검.md`에 남겨 두었다. 임의로 규칙을 확정하거나 점수를 바꾸지 않았다.

## 5. 추가 권장 개선

1. 대회 전 실제 사용할 휴대폰·태블릿에서 별도 테스트 선수로 로그인 → 평가 → 제출 → 검수 → 디브리핑을 짧게 확인한다.
2. 운영과 분리된 스테이징 DB에서 동시 접속/느린 네트워크 부하 검사를 한다.
3. 원본 사진은 보존하고 가벼운 화면용 미리보기 이미지를 별도 생성한다.
4. 이번 브라우저 회귀 테스트를 배포 전 자동 검사에 연결한다.
5. 시즌 종료 후 대회별 화면 모듈 분리를 단계적으로 진행한다. 저장 키와 점수 계산식은 회귀 테스트로 보호한다.

### 재실행 방법

Node.js 24 이상, 로컬 Chrome, Playwright가 필요하다. Playwright가 외부 설치 경로에 있으면 `KCL_PLAYWRIGHT_MODULE`에 모듈의 절대 경로를 지정한다.

```text
npm test
npm run test:browser:finals
npm run test:browser:release
```

브라우저 테스트는 로컬 서버와 메모리 SQLite만 사용한다. 운영 사이트로의 요청은 차단한다. 테스트 스크린샷은 Git에서 제외된 `tmp/release-qa/`에 저장한다.
