# 예선·결선 및 스테이션 사용성 검수 — 2026-10-14

## 변경 범위와 데이터 보호

- 운영 DB에 평가·명단·설정 변경, 기록 이관, 점수 재계산을 실행하지 않는다. 대회/디브리핑 공개 여부는 운영자가 결정한다.
- 사용자가 확정한 방식: 큰 구분은 **예선 / 결선**, MOC·KBC의 결선 안에서는 **본선 경기 / 최종 결승** 기록을 각각 보관한다.
- 대회/라운드/선수/심사위원 저장 식별자는 그대로 유지한다. 화면 명칭을 이유로 `본선` DB 행을 `결선`으로 바꾸거나 합산하지 않는다.

## 반영한 기능

1. 관리자·팀장 운영 설정과 실시간 순위의 상위 선택을 예선/결선으로 통일. 본선 경기가 별도인 대회만 접어 둔 경기 구분에서 변경한다.
2. 선수 디브리핑과 관리자 미리보기에 예선/결선 선택 추가. 선수 API도 선택한 구분의 정확한 라운드·참가번호만 조회한다. 결선 기록이 없으면 예선을 대신 보여주지 않는다. 기존 클라이언트의 API 호출 호환성은 유지한다.
3. KCR/IKRC 스테이션을 요약 카드로 표시: 번호 범위·인원·사용 용도, KCR 일차·프로세스. 선택한 카드만 펼쳐 수정한다.
4. KCR 기본 추가는 기존 정책인 다음 9명이며, 운영자가 시작/끝 번호를 수정할 수 있다. 일차 필터에서 감춰진 스테이션도 저장 시 빠지지 않는다.
5. 저장하지 않고 라운드를 바꾸면 확인한다. 취소하면 입력값과 선택 라운드를 유지한다. 추가·삭제·용도 변경도 미저장 상태를 표시한다.
6. 평가/검수·켈리브레이션 동작을 묶고, 백업/QR/선수 연결 등 보조 기능은 ‘운영 도구’에 모았다. 권한과 기존 버튼 핸들러는 유지한다.
7. KCAC 결선 창작패턴에 예선 개선 태그를 적합한 항목으로 계승한다. 완성도→디자인 완성도, 표면/선명도→표면 품질, 균형/위치→위치·대칭. 로제타 전용 리프·중심줄기 표현은 결선 선택지에서 제외한다. 예선 원본, 이미 저장된 태그·코멘트는 수정하지 않는다.

이번에 읽은 파일은 사용자가 첨부한 KCAC 09.09 PDF, KCR 260901 PDF, MOC/MOB/KTCC 26.05.18 PDF, KBC 0624 PDF, IKRC PDF다. 추출 텍스트와 주요 배점표 페이지를 대조했다. KCAC 18쪽 부록도 직접 렌더링해 확인했으며, 이번 첨부본은 창작패턴 1잔 + 센서리 2잔의 총 3잔 구성이다. 이전 검수 문서의 부록 불일치 우려는 이번 첨부본에서는 확인되지 않는다.

## 규정상 남은 확인 사항

- **KCR**: 규정 6.2는 팀별 분포에 따른 통계적 정규화를 요구하지만 상세 산식은 내부 운영 기준으로 비공개다. 현재 코드에는 공식/정규화 점수 필드 반영 경로가 있으나, 산식에 의한 자동 정규화를 이번에 추가하지 않았다. 내부 산식 또는 확정 공식점수가 필요하다. 심사 원점수를 임의 보정하지 않는다.
- **KBC**: 첨부본만으로 시간감점 구간표를 확정할 수 없어 기존 5초당 1점과 실격 기준을 유지했다. 다른 최신 운영표가 있으면 대조해야 한다.
- **MOC·KTCC**: 별도 공지되는 결선 히든미션의 문제/추가 판정 방식은 첨부 규정집만으로 확정할 수 없다.
- 일부 규정의 디브리핑 대상·시기와 사용자가 현장에서 확정한 웹 공개 방식이 다르다. 이번 변경은 선택한 구분의 정확한 결과만 제공하며, 이미 운영자가 정한 공개 정책이나 공개 스위치를 임의 변경하지 않는다.

## 테스트

- 운영과 분리된 메모리 SQLite에 실제 API 코드를 실행. 실제 선수 대상 테스트 제출·SMS 발송 없음.
- 신규: 7개 대회 예선/결선 공개 결과·순위 분리, 선수와 관리자 미리보기의 라운드별 평가표 동일성, 결선 미배정자의 예선 대체 노출 금지, 잘못된 구분의 OTP 미소모.
- 신규: 360/768/1440px 스테이션 키보드/마우스 조작, 펼치기·수정·추가·삭제·저장, 숨겨진 일차 보존, 미저장 라운드 변경 취소, stable ID, 9명 기본값, KCR/IKRC 모델 분리, 콘솔/리소스 오류와 가로 넘침 점검.
- 기존: KCAC 컵/점수/잠금/코멘트 독립성, 사진 없는 제출, 결선 영역별 계산, 7개 대회 평가→검수→순위→디브리핑, 중복 제출, 권한·블라인드, KCR 9컵/모바일 입력, D1 사용량·인덱스 등 전체 회귀 테스트.
