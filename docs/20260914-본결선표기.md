# 본·결선 공통 평가 표기

## 규정 확인

- KBC: `2026 KBC 룰북(26.07.01 수정).docx`의 4.4, 5.1~5.3에서 본/결선을 함께 규정한다. 에스프레소 + 창작메뉴, 프레젠테이션/서비스 및 머신·기물 운용을 같은 기준으로 평가한다. 각 맛과 설계 ×2, 총 60점, 시연 10분이다. 앱의 본선과 결선 평가항목·가중치가 동일한 것도 확인했다.
- MOC: `2026 MOC_룰북(26.05.18 수정).pdf`의 5~6쪽에서 본선 6분·12잔·최대 7점, 결선은 본선과 동일한 룰로 진행한다고 명시한다. 다만 결선 경기방식/미션은 본선 종료 후 별도 공지 대상이다. 기본 평가표는 함께 표시하되 실제 문제와 진행 기록을 합치지 않는다.
- 나머지 5개 대회는 현재 시스템의 예선/결선 구분을 유지한다. 예선과 결선을 동일한 평가표로 간주하지 않는다.

## 반영 방식

1. 관리자 대회/디브리핑 설정과 대회팀장 운영 설정에서 KBC·MOC는 평가 구분을 **예선 / 본·결선**으로 표시한다.
2. 본·결선 선택 시 **진행 단계**에서 본선 또는 결선을 선택한다. 선택만으로 대회가 오픈되지는 않으며 기존 설정 저장 버튼을 눌러야 반영된다.
3. 대회 카드에는 `본·결선 · 본선` 또는 `본·결선 · 결선`으로 현재 진행 단계를 함께 표시한다.
4. 서버에는 기존 `본선`, `결선` 값만 저장한다. 표시용 `본·결선`이 직접 전달되면 저장을 거부한다.
5. 기존 본선/결선 선수 번호, 점수, 순위, 검수, 디브리핑, 임시저장은 각각 독립적으로 유지한다. 기록 이관·점수 재계산·선수 재배정은 하지 않는다.
6. 이전에 결선으로 설정된 대회는 결선 선택을 유지한다. 평가 구분을 잠시 예선으로 바꿨다가 돌아와도 같은 화면에서 선택한 본선/결선 단계를 기억한다.

## 검증

- 실제 서버 코드를 메모리 DB에서 실행해 본선/결선 참가자 매칭, 공통 명칭의 저장 차단, 다른 대회 설정 불변, 기존 기록 및 명단 불변을 확인했다.
- 360px/768px/1440px 브라우저에서 관리자·팀장 설정, 저장 후 재표시, 다른 대회 옵션 유지, KBC 60점 계산 및 MOC 6분/섹션별 6잔 구성의 본선·결선 일치를 확인했다.
- 본선과 결선의 임시저장 키가 서로 다름을 확인했다.
- 전체 회귀 테스트 93개 실행 명령, 기존 주요 화면 70개 상태 및 본·결선 브라우저 검사, KCAC 제출→검수→순위/디브리핑 검사를 통과했다. Cloudflare Functions 빌드도 통과했다.
- GitHub main 앱 커밋 `38f4a93`, Cloudflare 배포 `15e5890f` 반영 완료. 실제 평가 페이지의 새 컨트롤·CSS v206·API 응답 및 390px/1440px 로그인 전 6개 페이지의 콘솔 오류 없음 확인.
- 운영 데이터를 읽기 전용으로 배포 전후 대조했다. 점수 837건·선수/팀 615건·대회 설정 7건 모두 내용 해시가 동일하다. 대회 오픈·라운드·디브리핑 공개 설정을 변경하지 않았다.

운영자가 실제 경기 라운드를 하나로 합치기를 원하는 경우에는 별도 확인이 필요하다. 이번 변경은 **공통 평가표의 명칭과 설정 화면 정리**이며 본선/결선 성적의 통합이 아니다.
