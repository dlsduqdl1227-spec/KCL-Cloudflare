# MOC 디브리핑 선수·라운드 연결 수정

## 수정 범위

- 내부 데이터베이스 ID를 MOC 참가번호로 취급하던 경로를 제거했습니다.
- 이름·연락처·대회로 본인을 확인한 뒤, 라운드별 참가번호와 정확히 일치하는 공식 기록만 조회합니다.
- 기록이 없을 때 점수 payload의 숫자나 이름 부분 일치로 타인의 기록을 가져오던 대체 검색을 MOC에서 제외했습니다.
- 관리자 미리보기와 선수 디브리핑은 동일한 조회 함수를 사용합니다.
- 예선·본선·결선 순위와 총점을 각각 표시합니다.

## 보존 사항

원본 점수, 코멘트, 선수 명단, 순위 계산, 동점 처리, 대회 운영·공개 설정은 수정하지 않습니다. 다른 대회의 조회 동작은 이번 변경 범위에 포함하지 않습니다. 데이터베이스 마이그레이션은 없습니다.

## 검증

- 읽기 전용으로 가져온 운영 데이터 사본: MOC 178명 전수 대조, 공식 평가 167건 각각 본인에게만 연결, 미평가 11명은 빈 결과.
- 관리자 미리보기와 선수 조회의 점수·순위 객체 일치 확인.
- 실제 API와 임시 SQLite 테스트: 내부 ID 충돌, 라운드별 번호 재사용, 부분 이름, 기록 없음, 켈리브레이션·미검수 제외, 원본 보존 확인.
- 브라우저 390/768/1440px: 라운드 표시, 카드 개수, 미리보기·선수 화면 일치, 가로 넘침·JavaScript 오류 확인.
- 프로젝트 등록 테스트 명령 108개 모두 통과. Cloudflare Pages Functions 빌드 통과.

운영 환경에서 실제 선수 인증번호를 발송하거나 테스트 평가를 저장하지 않았습니다. 배포 전후 운영 테이블의 건수와 SHA-256을 대조합니다.

## 재실행

`npm run test:moc-debrief`

브라우저 테스트에는 Playwright가 필요하며, 환경에 따라 `KCL_PLAYWRIGHT_MODULE`로 설치된 모듈 경로를 지정할 수 있습니다.
