# KCR 스테이션 정리 · 로그인 유지

## 변경 범위

- KCR 등록·권한 관리에서 예선 날짜 입력·일괄 변경·날짜 열을 숨김. 기존 날짜와 부가정보는 선수 수정 시에도 보존.
- KCR 켈리브레이션 진입 버튼 하나로 통합. 팀 등록 없이 스테이션을 선택하며 구버전 전체 켈리브레이션 제출도 스테이션 모드로 저장.
- 스테이션 사용 모드를 대회평가 / 켈리브레이션 / 공용으로 명시. 신규 스테이션 기본값은 대회평가. 진입 시 최신 설정을 조회하고 늦게 도착한 응답은 다른 대회·평가 화면을 변경하지 않음.
- 헤드·센서리의 공식 점수는 선택한 스테이션에 독립 저장되며 모두 공식 평균에 포함. 켈리브레이션은 공식 평균·순위에서 제외.
- 켈리브레이션 비교와 중복 제출 판정은 스테이션 고유 ID 우선. 스테이션 이름 재사용으로 다른 스테이션 점수가 합쳐지는 문제 방지.
- 공통 뒤로가기·홈 버튼을 화면 왼쪽 위로 통일. 기존 화면별 뒤로가기 동작과 작성 중 이동 확인 유지. 순위 상세에서 뒤로가기는 해당 순위 목록으로 이동.
- KCR 스테이션 설정의 모바일/태블릿 CSS 우선순위 충돌 수정. 입력란·삭제 버튼의 가로 잘림 방지.
- 강도 라벨의 `(점수 아님)` 문구만 제거. 점수 범위·가중치·강도값은 변경하지 않음.
- 로그인 토큰만 별도 보관하고 재접속 시 서버에서 유효성·최신 권한 확인. 홈 이동·새로고침 시 로그인 복원. 보안번호/비밀번호를 새 저장소에 보관하지 않음.
- 명시적 로그아웃 시 로컬 로그인 정보와 해당 서버 세션 폐기. 평가 초안과 제출 점수는 삭제하지 않음. 기존 서버 세션 유효기간(로그인 후 6시간)은 유지하며 만료 시 재로그인 필요.

## 검증

- 95개 기존/신규 테스트 명령 전체 통과.
- 실제 RPC + 폐기 가능한 SQLite에서 헤드·센서리 제출, 다른 팀 소속, 연속 스테이션 평가, 검수, 평균 산출, 켈리브레이션 순위 제외 검증.
- 같은 참가번호의 다른 켈리브레이션 스테이션 저장/비교 및 재사용된 스테이션 이름의 고유 ID 분리 검증.
- 신규 브라우저 테스트: 360 / 768 / 1440px에서 관리자·팀장·헤드·심사위원 메뉴, 스테이션 필터, 사용 모드, 입력 컨트롤 경계 확인.
- 실제 로그인 → 홈 → 평가 재접속 → 새로고침 → 로그아웃 → 재접속, 폐기된 토큰 복원 차단, KCR 선수 수정 시 기존 날짜/추가정보 보존 확인.
- 기존 브라우저 테스트 201, 203, 204, 206, 208 통과: 본결선 평가, 전체 공개 페이지, 검수·디브리핑, 라운드 선택, 독립 순위/내보내기.
- Pages Functions 빌드 성공. 운영 점수·선수 등록을 사용한 테스트 제출 없음.

## 운영 반영 제한

현재 KCR 예선 설정만 스테이션 1(고유 ID station3)은 켈리브레이션 전용으로 유지하고, 스테이션 2·3(station4·station5)은 대회평가 전용으로 정정한다. 결선의 사용 모드/참가번호 범위/프로세스와 다른 6개 대회 설정은 변경하지 않는다. 설정 저장은 조회한 원본과 일치할 때만 실행하는 조건부 갱신으로 처리한다.
