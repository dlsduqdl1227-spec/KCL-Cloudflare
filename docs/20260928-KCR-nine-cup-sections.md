# KCR 9명 평가 섹션 반영 (2026-09-28)

## 운영 설정

- 예선 226명: 1일차 1~113번, 2일차 114~226번. 하루 13개 대회용 스테이션이며 각 9명, 마지막만 5명.
- 대회용 스테이션 1 = 1~9번, 2 = 10~18번. 13 = 109~113번, 14 = 114~122번, 26 = 222~226번.
- 기존 켈리브레이션의 내부 ID는 유지하고 표시 순서만 마지막(스테이션 27)으로 배치. 켈리브레이션 범위는 1~9번이며 공식 점수와 분리.
- 결선 40명은 9/9/9/9/4명, 5개 섹션. 결선 진출자 및 결선 참가번호는 관리자가 확정해야 함. 선수의 결선 번호나 현재 진행 라운드는 자동 변경하지 않음.
- 실제 운영 DB의 KCR 설정 한 행만 사전 값 일치 조건(CAS)으로 변경. KCR에 기존 평가가 없는 것을 확인한 뒤 적용.
- 전체 기존 평가 837건, 선수 614건 및 다른 대회 설정 6건이 변경 전후 동일함을 해시 비교로 확인.

## 웹앱 수정

- KCR 새 스테이션 추가 시 이전 대회용 스테이션 끝 번호 다음부터 9명 범위를 제안. 켈리브레이션 범위는 연속 번호 계산에서 제외.
- 관리자 입력 범위는 저장 후 그대로 유지. 자동 보정이나 페이지 진입 때의 일괄 재설정 없음.
- 과거 7컵 임시저장 복원 시 현재 범위를 덮어쓰지 않고, 컵 번호가 일치하는 점수·코멘트·잠금 상태를 복원. 새 컵은 독립된 초기 상태.
- 범위 변경 전 임시저장 원본은 로컬 저장소에 별도 보관. 이전에 보고 있던 컵의 DOM 입력값이 다른 컵에 복사되지 않도록 차단.
- IKRC 및 다른 대회 스테이션 기본값은 변경하지 않음.

## 검증

`test:kcr-nine-cups`에서 226명 중복/누락 없음, 40명 결선 범위, 9개 개별 제출, 라운드·켈리브레이션 격리, 관리자 수정 유지, 7컵 임시저장 확장 및 범위 이동, 390/1440px 화면을 검증.

운영 자료는 테스트용 제출로 변경하지 않음. 실제 제출 테스트는 격리된 로컬 DB에서 수행.
