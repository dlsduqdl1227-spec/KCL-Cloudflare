# 20260803 업데이트

## IKRC

- 커핑 기준을 `11g 홀빈 / 200g 물 / 93℃ / 600~700µm / 4분 브레이킹`으로 정정했습니다.
- 헤드 심사위원의 공식 평가 점수를 일반 심사위원 점수와 동일하게 검수·순위·총점에 반영합니다.
- 켈리브레이션 화면에 `내 팀`과 `전체 심사위원` 범위를 분리했습니다.
- 여러 헤드 심사위원이 같은 샘플을 확인해도 확인 완료 상태를 `헤드 계정 + 범위 + 라운드 + 샘플`별로 저장해 서로 덮어쓰지 않습니다.
- 팀 범위에서는 해당 팀 제출만, 전체 범위에서는 모든 팀 제출을 비교합니다.

## MOB

- 점수바를 1점 `아주나쁨`, 2점 `나쁨`, 3점 `보통`, 4점 `좋음`, 5점 `아주좋음`으로 통일했습니다.
- 0.2점 단위는 `보통 중 나쁨/보통/좋음/아주좋음`처럼 현재 정수 구간 안의 세부 수준으로 표시합니다.
- 각 점수 슬라이더에 `점수 고정` 버튼을 추가하고 임시저장 복원 시 잠금 상태도 함께 복원합니다.
- 검수 목록·검수 상세·디브리핑에서 총점을 확인할 수 있게 복원했습니다.
- 센서리 속성별 코멘트 입력은 제거하고 `MOB 전체 종합 코멘트` 한 곳에서 작성하도록 정리했습니다.

## 공통 자동 코멘트

- 자동 코멘트 예시를 3개에서 2개로 줄였습니다.
- 심사위원명·대회·평가 대상을 기준으로 문장 순서와 도입 표현을 안정적으로 바꿔 20~30명 규모에서 같은 형식의 반복을 줄였습니다.
- 점수 구간에 맞는 긍정·보완 표현을 유지하며, 낮은 점수가 과도하게 긍정적으로 해석되지 않도록 회귀검사를 추가했습니다.

## 자동검사

- IKRC 헤드 공식 점수의 검수·순위 반영을 통합 검사합니다.
- 서로 다른 헤드 계정과 팀/전체 켈리브레이션 확인 상태가 충돌하지 않는지 검사합니다.
- MOB 총점 표시, 점수 고정, 통합 센서리 코멘트 구조를 검사합니다.
- 동일 조건의 심사위원 30명 자동 코멘트가 2개 예시와 다양한 문장 구성을 유지하는지 검사합니다.

## 켈리브레이션 목적 분리

- 평가 진입을 `대회평가`, `전체 켈리브레이션`, `팀별 켈리브레이션` 세 버튼으로 분리했습니다.
- 전체 켈리브레이션은 기존 1·2·3팀 배정과 관계없이 모든 헤드·센서리 심사위원을 `전체 켈리브레이션팀` 한 그룹으로 저장합니다.
- 팀별 켈리브레이션과 대회평가는 운영팀장이 처음 지정한 팀 번호를 그대로 사용합니다.
- 전체/팀별 켈리브레이션은 공식 검수·순위·총점에서 제외하고 서로 다른 데이터 묶음으로 저장합니다.
- 헤드 심사위원도 켈리브레이션에 참여하며, 대회평가를 선택한 헤드 점수는 공식 합산에 포함합니다.
- 같은 심사위원이 같은 컵을 전체 켈리브레이션, 팀별 켈리브레이션, 대회평가에서 각각 독립 제출할 수 있도록 중복 판정을 분리했습니다.

## MOB 수기 종합 코멘트

- MOB 종합 코멘트 자동 생성·자동 입력 버튼을 제거하고 심사위원 수기 작성만 저장합니다.
- 속성 점수와 스마트태그를 변경하면 속성별 참고 문구만 즉시 갱신되며 종합 코멘트에는 복사되지 않습니다.
- 참고 표현은 속성마다 최대 2개만 노출해 반복과 과밀을 줄였습니다.
- 스마트태그 그룹 표기를 `주요 표현`과 `보완 표현`으로 통일했습니다.
- 검수 화면에서도 MOB 종합 코멘트 자동 생성 기능을 제외해 원 심사위원의 수기 의견을 유지합니다.

## 추가 회귀검사

- 실제 IKRC 전체·팀별 켈리브레이션과 대회평가 데이터를 함께 제출해 저장 그룹, 공식 검수 분리, 백업 분류, 헤드 포함 여부를 통합 검사합니다.
- 전체 켈리브레이션과 팀별 켈리브레이션의 확인 상태가 헤드 계정별로 충돌하지 않는지 검사합니다.
- MOB 수기 종합 코멘트와 참고 문구·스마트태그 표준화가 유지되는지 검사합니다.

## IKRC 헤드 공식평가 검수 보강

- 헤드 심사위원의 대회평가 제출값을 본인 검수 목록에 그대로 유지하고, 점수 수정 시 총점을 다시 계산해 공식 점수로 저장합니다.
- 헤드 검수 화면에서 같은 라운드·같은 샘플·같은 팀의 최신 공식 점수를 심사위원별 읽기 전용 표로 비교합니다.
- 비교표에 헤드 본인 점수, 일반 심사위원 점수, 속성별 평균·표준편차와 총점 평균·표준편차를 함께 표시합니다.
- 다른 팀 점수와 켈리브레이션 점수는 공식평가 비교에서 제외합니다.
- 헤드는 다른 심사위원 점수를 비교할 수만 있고 수정할 수 없으며, 본인 제출만 검수·수정·완료 처리할 수 있습니다.
- 헤드 점수가 실제 IKRC 순위 평균에 포함되는지 통합 회귀검사로 확인합니다.
