# 2026-07-30 IKRC 업데이트

## 적용 내용

1. 스테이션 추가·삭제 허용
   - 기존 IKRC 점수가 있어도 스테이션 구성을 변경할 수 있습니다.
   - 스테이션을 삭제해도 이미 제출된 점수와 백업 데이터는 삭제하지 않습니다.
   - 스테이션 ID와 표시 이름을 고정해 순서 변경이나 중간 삭제 후에도 과거 데이터 연결을 유지합니다.

2. 스테이션 재배치 후 데이터가 사라져 보이던 문제 수정
   - 기존에는 같은 심사위원의 여러 제출을 심사위원 단위의 최신 1건으로 잘못 합쳤습니다.
   - 이제 `라운드 + 심사위원 + 역할 + 스테이션/샘플` 단위로 최신 제출을 구분합니다.
   - 센서리 헤드만 제출된 샘플도 켈리브레이션 목록에 표시합니다.
   - 검수 완료 후 재제출된 데이터는 다시 미검수로 표시합니다.

3. 휴대폰 엑셀 백업 개선
   - 외부 CDN이 아닌 앱 내부의 XLSX 라이브러리로 실제 `.xlsx` 파일을 생성합니다.
   - 휴대폰에서는 생성 후 저장·열기·공유 화면을 표시합니다.
   - 지원 기기에서는 카카오톡, 파일 앱, Excel 앱 등 시스템 공유 메뉴로 전달할 수 있습니다.

4. 참여 인원 안내
   - 등록 가능한 참여 인원 수에는 별도의 제한을 두지 않습니다.
   - 동시에 운영할 수 있는 현재 설정 범위는 최대 12개 스테이션, 스테이션별 최대 50개 코드입니다.

5. 심사 웹 QR
   - 운영팀장과 팀장 화면에 `심사 웹 QR` 버튼을 추가했습니다.
   - QR에는 선택한 대회 코드가 포함된 평가 웹 주소가 들어갑니다.
   - 기본 카메라로 스캔하면 평가 로그인 화면으로 이동하고 로그인 후 해당 대회를 먼저 선택합니다.
   - 링크 복사와 QR 이미지 저장도 지원합니다.

6. 휴대폰 뒤로가기
   - 휴대폰 왼쪽 아래에 고정 `← 뒤로가기` 버튼을 추가했습니다.
   - 카카오톡·안드로이드 시스템 뒤로가기도 현재 평가 앱의 이전 단계로 처리합니다.

7. IKRC Acidity 스마트태그
   - 한글과 영어가 섞여 있던 기존 10개 개념을 대회 화면 전체의 표기 방식에 맞춰 한국어로 통일했습니다.
   - 주요 표현: 선명한, 부드러운, 과즙감 있는, 밝은, 강렬한, 산뜻한, 섬세한
   - 보완 표현: 평평한, 신맛이 도드라진, 거친

## 데이터 확인

- 배포 전 Cloudflare D1 전체 SQL 백업을 생성했습니다.
- 배포 전 운영 IKRC 예선 집계:
  - 센서리 헤드 심사위원: 6건 / 6샘플
  - 센서리 심사위원: 12건 / 6샘플
- 스테이션 삭제·재배치 과정에서 위 점수 레코드가 삭제된 것이 아니라 기존 화면 집계에서 일부가 숨겨져 보였던 상태로 확인했습니다.

## 전체 기능 중복·누락 재점검

1. 등록·권한 관리 기능 일원화
   - 선수·심사위원·팀장·관리자 계정 관리는 `/registry/` 한 곳에서만 처리하도록 정리했습니다.
   - 통합 운영관리 화면에 `등록·권한 관리` 바로가기 버튼을 추가했습니다.
   - 운영 화면에 남아 있던 예전 계정관리 함수와 스타일을 제거했습니다.
   - 운영 화면을 열 때 사용하지 않는 전체 계정·전화번호 목록을 조회하지 않도록 서버 응답을 축소했습니다.

2. IKRC 중복 입력 방식 제거
   - 현재 운영 방식인 `스테이션 선택 → 지정 샘플 자동 구성`만 유지합니다.
   - 화면에서 이미 제거된 옛 범위 입력·개별 컵 추가 코드를 삭제했습니다.
   - 스테이션 정보 없이 IKRC 평가를 시작할 수 없도록 시작 단계 검증을 추가했습니다.

3. 검수 화면 중복 DOM 정리
   - 자동저장 상태 영역을 새로 덮어쓰지 않고 기존 요소를 갱신하도록 변경했습니다.
   - 같은 ID가 동적으로 반복 생성될 가능성을 제거했습니다.

4. Stage114 기능 무결성 자동검사 추가
   - 중복 정적 ID·중복 함수 선언 검사
   - 버튼 이벤트 함수 누락 검사
   - 공개 화면 RPC와 서버 액션 연결 누락 검사
   - 7개 대회 제출 함수 및 검수·순위·최종정리·백업 액션 존재 검사
   - 제거된 구형 계정관리·IKRC 수동 컵 기능이 다시 들어오지 않는지 검사

## 센서리 스마트태그·KCAC 코멘트 일관성 개선

1. KCR형 공통 센서리 태그 적용
   - KCR의 계열형 향미 구조와 긍정·보완 구분을 공통 센서리 태그 모듈로 분리했습니다.
   - 적용 대회: KBC, MOB, IKRC, KCAC 결선 센서리.
   - 적용 항목: 플레이버, 단맛, 산미, 클린컵, 마우스필, 밸런스 등 감각 평가 항목.
   - MOC, KTCC 및 서비스·테크니컬·프레젠테이션 스마트태그는 변경하지 않았습니다.

2. KCAC 종합 코멘트 판정 수정
   - 선택 태그의 긍정·보완 소속을 코멘트 생성 서버까지 별도로 전달합니다.
   - 보완 태그가 선택되면 점수 문장이 부정 관찰을 덮지 않도록 종합 톤을 제한합니다.
   - 낮은 점수에서는 긍정 태그가 있더라도 `기준 충족`, `안정적`, `완성도 높음`으로 생성되지 않게 했습니다.
   - 각 후보 문장에 강점 관찰과 보완 관찰을 명시적으로 포함합니다.

3. KCAC 점수 슬라이더 공통화
   - KCAC 전용 커스텀 슬라이더를 제거했습니다.
   - 다른 대회와 동일한 공통 `score-slider` 스타일과 0.2점 단위 보정을 사용합니다.

4. Stage115 센서리 일관성 자동검사 추가
   - IKRC 산미 용어 한국어 통일 검사
   - KBC·MOB·IKRC·KCAC 센서리 적용 범위 검사
   - 비센서리 항목 미변경 검사
   - KCAC 부정 태그·낮은 점수 코멘트의 긍정 오판 방지 검사
   - KCAC 전용 구형 슬라이더가 다시 들어오지 않는지 검사

## 스마트태그 계열 선택·모바일 레이아웃 개선

1. 향미 계열 버튼 직접 선택
   - `견과·코코아 계열` 같은 1차 계열 버튼 자체를 평가 근거로 바로 저장합니다.
   - 세부 특성을 선택하면 같은 계열의 상위 선택을 세부 선택으로 교체합니다.
   - 세부 특성이 선택된 상태에서 계열을 다시 선택하면 세부 선택을 계열 선택으로 교체합니다.
   - 기존 `향미 계열 > …` 형식으로 저장된 값은 새 경로로 자동 변환합니다.

2. KCR형 카드 그리드 공통화
   - KBC, MOB, IKRC, KCAC 결선 센서리와 검수 화면에 균일한 카드 그리드를 적용했습니다.
   - 휴대폰에서는 한 줄에 두 개 카드로 표시하고 긴 문구는 카드 안에서 줄바꿈합니다.
   - 서비스·테크니컬·프레젠테이션 스마트태그는 기존 레이아웃을 유지합니다.

3. Stage116 자동검사 추가
   - 1차 향미 계열이 실제 선택값인지 검사
   - 계열 선택과 세부 선택이 서로 교체되는지 검사
   - 기존 저장 경로 자동 변환 검사
   - 적용 대회 및 모바일 2열 카드 레이아웃 검사

## 스마트태그 상세 패널 단일 열림 처리

1. 선택값과 화면 열림 상태 분리
   - 여러 계열의 태그를 선택해도 선택값은 그대로 유지합니다.
   - 화면에는 마지막으로 누른 1차 카테고리의 상세 내용만 표시합니다.
   - 3차 구조가 있는 경우에도 마지막으로 누른 2차 카테고리 하나만 펼칩니다.

2. 적용 범위
   - KBC, MOB, KCAC 평가 화면
   - KBC, MOB, IKRC, KCAC 공통 검수 화면
   - KCR과 IKRC의 기존 단일 열림 동작은 유지합니다.

3. Stage117 자동검사 추가
   - 카테고리 전환 시 이전 패널이 닫히는 상태 검사
   - 선택된 태그가 패널 열림 상태와 분리되는지 검사
   - 평가 시작 및 검수 대상 전환 시 열림 상태 초기화 검사
